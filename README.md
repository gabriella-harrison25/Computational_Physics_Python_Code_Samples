# Computational_Physics_Python_Code_Samples
PX281 - Computational Physics Assignment Code Samples

This module seeks to expand students' ability to apply Python in Computational Mathematics fields. The major components include data science tasks, utilizing integration and differentiation methods in applied mathematics, modelling physics with random numbers, and utilizing ordinary differential equations in Python to ensure efficiency in solutions. The module culminates in a term-long project where skills are applied to real experimental data within a particular field of physics.

## Project 1
Apply the scipy curve_fit function to determine the optimal curve for projectile data. Identify and fix the errors in a Newton-Raphson Root-finding method and plot the ideal curve found.
